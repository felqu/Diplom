# Контракты взаимодействия

Контракты являются публичным соглашением между сервисами. Изменения должны быть обратно совместимыми либо выпускаться с новой версией (`v2`).

- `openapi/` — синхронные HTTP-интерфейсы.
- `events/` — схемы асинхронных доменных событий.
- `proto/` — gRPC-контракты при их использовании.
